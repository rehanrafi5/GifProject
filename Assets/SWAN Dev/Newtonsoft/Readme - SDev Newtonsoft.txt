
* Note that the Newtonsoft Json plugin included in ProGIF packages is now provided as a separate Unity package. You can find the file (Newtonsoft.Json Plugin) in the folder and install as needed.

Starting from Unity2020 and newer, Newtonsoft.Json should be included in the Unity packages by default. But if your project does not have the plugin installed (you will see some related errors), then you can install our Newtonsoft JSON plugin.
